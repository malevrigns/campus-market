# 动态 Agent 实施计划

目标：将固定工具/模型的购物助手改为可管理、发布和审计的 Agent 系统，验证后将本轮及前一轮已授权项目改动提交到现有 GitHub 仓库。

采用数据库能力目录与不可变发布快照；沿用当前 Go/SQLite 服务。管理员可组合模型、内置只读工具与受信任的 MCP 工具。相比直接覆盖运行参数，发布版本可回溯且不会改变正在执行的 run；相比引入新的服务框架，能够沿用已经验证的身份与交易边界。

管理员由后端 `ADMIN_USER_IDS` 明确配置，不自动授予首位注册用户、不接受客户端角色。模型与 MCP 连接及凭据通过服务器配置白名单提供，配置台只引用连接 ID。新增模型/工具/Agent、绑定、编辑、发布、停用、删除不需要改代码或重新部署；新增网络信任边界和密钥需运维配置。

- [x] `agent_catalog.go`：能力 CRUD、Agent 草稿 CRUD、乐观锁、原子发布与历史版本、能力引用保护、发布快照；默认助手/旧会话兼容迁移。
- [x] `agent_mcp.go`：Streamable HTTP initialize / initialized / tools/list / tools/call，JSON 与 SSE 响应，会话与版本头、大小/时间限制、禁止重定向、只读工具白名单。
- [x] `agent.go`：从已发布配置决定模型/系统提示/工具/限额；会话绑定助手；运行保存版本快照；运行前和执行工具前校验停用状态；日志只记录工具名称和状态。
- [x] 前端：管理员能力与 Agent 配置台、草稿编辑/发布/停用/历史、模型/工具绑定；普通用户切换已发布助手，展示版本及实际工具执行状态；移动端可操作。
- [x] 验证：非管理员拒绝、草稿不生效/发布立即生效、旧 run 快照稳定、并发编辑冲突、停用权限、越权线程、MCP 协议/输入 schema/未知工具拒绝；浏览器实际创建与发布。
- [x] 更新运行/API 文档、环境样例和测试；检查待提交文件、运行全套检查。提交动作：校验后 commit + 正常 push（不 force），以 GitHub commit 与 CI 记录作为发布结果凭据。

MCP 采用官方 2025-06-18 Streamable HTTP 协议，只接入运维信任且管理员明确绑定的只读工具。不会把外部声明的 readOnlyHint 当成系统隔离或数据权限保证。写工具审批、RAG 与跨节点运行不在这次“动态配置能力”交付内，不伪称实现。
